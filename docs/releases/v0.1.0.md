The first release of git-ex-machina, for Linux as an AppImage.

## What's in it

- **Your repositories in one window**: add the ones you have, clone new ones over SSH, or make a folder a repository where it is (with Git LFS for its binary files, if you like).
- **History with its graph**: select one commit or several, and inspect what each one changed.
- **Fetch, pull, push**, and publish a branch that only exists on your machine.
- **Commit** from the uncommitted changes: stage, unstage, discard. Cherry-pick and revert commits, check out a branch, and set changes aside.
- **Pull requests on GitHub**: sign in with a one-time code, read a pull request beside its commits, review it line by line, and squash and merge it.
- **Repository settings**: the settings button beside commit search opens every page of GitHub's settings (general, branches and rules, people, Actions, secrets and variables, environments, webhooks, Pages, code security, deploy keys, autolinks, and deleting the repository), next to what lives on your computer (remotes, your identity, Git LFS patterns). If you aren't an admin, GitHub's settings are there to read.
- **Tidy up merged branches**: see the branches that are already merged and delete them, and have a merge from the app delete its local branch when the repository is set to.
- **Updates itself**: when a newer version is out, the corner of the sidebar offers it. It downloads, checks it against GitHub's checksum, and asks you to restart, with what changed.

## Installing

Download `git-ex-machina-x86_64.AppImage`, make it executable (`chmod +x git-ex-machina-x86_64.AppImage`) and run it. Keep it somewhere you can write to, such as `~/Applications`, so it can update itself in place. It needs `git` installed.
